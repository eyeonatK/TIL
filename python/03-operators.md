# Python 연산자 (Operators)

파이썬에서 제공하는 기본 연산자의 종류와 특징, 그리고 조건부 표현식(삼항 연산자) 정리.

---

## 1. 산술 연산자 (Arithmetic Operators)

수치 데이터를 계산할 때 사용하는 기본 연산자.

| 연산자 | 설명 | 예시 | 결과 |
| :--- | :--- | :--- | :--- |
| `+` | 덧셈 | `10 + 3` | `13` |
| `-` | 뺄셈 | `10 - 3` | `7` |
| `*` | 곱셈 | `10 * 3` | `30` |
| `/` | 나눗셈 (항상 float 반환) | `10 / 2` | `5.0` |
| `//` | 바닥 나눗셈 (정수 몫만 반환) | `10 // 3` | `3` |
| `%` | 나머지 연산 | `10 % 3` | `1` |
| `**` | 거듭제곱 | `2 ** 3` | `8` |

---

## 2. 비교 연산자 (Comparison Operators)

두 피연산자의 크기나 일치 여부를 비교하며, 반환값은 항상 불리언(`bool`) 타입이다.

| 연산자 | 설명 | 예시 (`a = 10`, `b = 20`) |
| :--- | :--- | :--- |
| `==` | 값이 같으면 참 | `a == b` -> `False` |
| `!=` | 값이 다르면 참 | `a != b` -> `True` |
| `>` | 좌항이 우항보다 크면 참 | `a > b` -> `False` |
| `>=` | 좌항이 우항보다 크거나 같으면 참 | `a >= b` -> `False` |
| `<` | 좌항이 우항보다 작으면 참 | `a < b` -> `True` |
| `<=` | 좌항이 우항보다 작거나 같으면 참 | `a <= b` -> `True` |

---

## 3. 논리 연산자 (Logical Operators)

비교식이나 불리언 값을 결합하여 복합 조건을 평가한다.

| 연산자 | 설명 | 동작 규칙 |
| :--- | :--- | :--- |
| `and` | 논리곱 | 양쪽 피연산자가 모두 참일 때만 `True` 반환 |
| `or` | 논리합 | 한쪽 피연산자라도 참이면 `True` 반환 |
| `not` | 논리부정 | 참은 거짓으로, 거짓은 참으로 반전 |

---

## 4. 멤버십 연산자 (Membership Operators)

시퀀스(문자열, 리스트, 튜플)나 컬렉션 내부에 특정 원소가 존재하는지 검사한다.

```python
langs = ["python", "java", "c"]

print("python" in langs)      # True
print("golang" not in langs)   # True
```

---

## 5. 삼항 연산자 (조건부 표현식)

단순 `if-else` 분기를 한 줄로 간결하게 표현하여 변수에 값을 바로 할당할 때 사용한다.

### 문법
```python
<참일 때 값> if <조건식> else <거짓일 때 값>
```

### 활용 예시
```python
score = 80
# 70 이상이면서 100을 나눈 몫이 1인지 검사
result = "Pass" if (score >= 70 and 100 // score == 1) else "Fail"

print(result)  # Pass
```
