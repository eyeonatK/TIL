# Python 타입 힌트 (Type Hints)

파이썬의 동적 타입 한계를 보완하고 코드 가독성 및 안정성을 높이기 위한 타입 어노테이션(Type Annotation) 문법 정리.

---

## 1. 타입 힌트 개요

파이썬은 런타임에 타입을 검사하지 않는 동적 언어이지만, 명시적으로 자료형을 표기하여 협업 효율과 IDE 자동완성 기능을 극대화할 수 있다.

* **비강제성**: 타입 힌트가 실제 대입된 값과 일치하지 않아도 파이썬 인터프리터는 런타임 에러를 발생시키지 않는다.
* **용도**: 코드 가독성 증대, IDE의 정적 분석 지원, `mypy` 등과 결합한 빌드 전 버그 검출.

---

## 2. 변수 타입 힌트 문법

### 2.1 기본형
```python
name: str = "Alice"
age: int = 25
height: float = 172.5
is_active: bool = True
```

### 2.2 컬렉션 (Collections)
Python 3.9+부터 내장 타입을 그대로 제네릭 타입 힌트로 사용할 수 있다.

| 자료형 | 타입 힌트 표기 | 설명 |
| :--- | :--- | :--- |
| **List** | `list[int]` | 정수 요소로 구성된 리스트 |
| **Dict** | `dict[str, int]` | 문자열 Key와 정수 Value로 이루어진 딕셔너리 |
| **Set** | `set[str]` | 문자열 요소로 구성된 집합 |
| **Tuple (고정길이)** | `tuple[str, int]` | 0번 인덱스는 문자열, 1번 인덱스는 정수인 2칸 튜플 |
| **Tuple (가변길이)** | `tuple[int, ...]` | 정수 원소가 임의의 개수로 들어올 수 있는 튜플 |

### 2.3 다중 타입 (Union Type)
파이썬 3.10+부터 파이프(`|`) 연산자를 통해 여러 타입을 허용할 수 있다.

```python
# 정수 또는 실수를 담는 리스트
numbers: list[int | float] = [1, 2.5, 3]

# None을 허용하는 변수 (Optional)
user_id: int | None = None
```

---

## 3. Ellipsis (`...`) 활용 용도

| 활용처 | 예시 | 설명 |
| :--- | :--- | :--- |
| **가변 길이 튜플** | `tuple[str, ...]` | 문자열 원소를 임의의 길이로 허용하는 튜플 타입 정의 |
| **미구현 플레이스홀더** | `def task(): ...` | `pass`를 대신하여 빈 블록이나 추상 메서드를 표기할 때 사용 |
| **다차원 슬라이싱** | `arr[..., 0]` | 다차원 넘파이 배열 등에서 나머지 전체 축을 일괄 지정할 때 사용 |
